# Chubby Lung

## How to Run
1. **Clone Repository นี้:**
```bash
   git clone [https://github.com/USERNAME/chubby-lung.git](https://github.com/USERNAME/chubby-lung.git)
   cd chubby-lung
```

2. **ติดตั้งไลบรารีที่จำเป็น:**
```bash
   pip install streamlit pandas openai
```
3. **ใส่ API Key:**
   เปิด app.py ด้วย VScode แล้วใส่ API Key บรรทัดที่ 18 TYPHOON_API_KEY = "ใส่ Apikey ตรงนี้"

4. **รัน Web Application:**
```bash
   streamlit run app.py
```
